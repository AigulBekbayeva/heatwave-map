    Definition

    A heatwave is at least 3 consecutive days on which the daily maximum temperature is above the local 95th percentile for that calendar day. Every day inside such a run counts as a heatwave day.

    The percentile is computed separately for each location and calendar day from 2000–2025, using a 15-day window centred on that day (390 values each). So a "hot day" in Oslo and in Riyadh are both unusual for that place and time of year.

    Data & caveats

    Daily Tmax from ERA5 (ECMWF / Copernicus, ~25 km grid) via the Open-Meteo Historical Weather API, local-time days. Each country is sampled at its capital, so large countries are represented by one location. The baseline (2000–2025) already includes recent warm years; compared with an older baseline such as 1961–1990 it gives fewer heatwave days and a more conservative trend.
